## 🚀 Quick Start

1. **Clone this repo** and read `QUICK_START.md`
2. **Set up tools** using `resources/tools_setup.md`
3. **Install dependencies:** `pip install -r scripts/requirements.txt`
4. **Run lead generation:** `python scripts/lead_generation.py`
5. **Send first outreach** using `templates/email_templates.md`
6. **Track everything** in `tracking/`
