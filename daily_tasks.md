# ✅ Daily Tasks Checklist

Use this every day to stay on track toward $1M.

---

## 🌅 Morning Routine (8:00-9:00 AM)

### Review & Plan (15 min)
- [ ] Check yesterday's metrics in `tracking/metrics_tracker.csv`
- [ ] Review replies in email inbox
- [ ] Check LinkedIn notifications
- [ ] Update `tracking/client_tracker.csv` with new info
- [ ] Set today's 3 most important tasks (MIT)

### Mindset (15 min)
- [ ] Review revenue target and current progress
- [ ] Read one section of `business_model.md`
- [ ] Visualize closing a deal today

---

## 📧 Outreach Block (9:00-11:00 AM)

### Lead Research (30 min)
- [ ] Find 10-20 new leads using Apollo.io or LinkedIn
- [ ] Run `python scripts/lead_generation.py --count 20`
- [ ] Verify contact emails (use Hunter.io)
- [ ] Add to `tracking/client_tracker.csv`

### Email Outreach (60 min)
- [ ] Send 20-30 cold emails (use `templates/email_templates.md`)
- [ ] Personalize each email (agency name, specific pain point)
- [ ] Run `python scripts/email_outreach.py` for bulk sends
- [ ] Log sent emails in `tracking/metrics_tracker.csv`

### LinkedIn (30 min)
- [ ] Send 20-25 connection requests (agency owners)
- [ ] Reply to any messages
- [ ] Comment on 5 relevant posts
- [ ] Post one piece of content (optional, 3x/week)

---

## 📞 Calls & Meetings Block (11:00 AM - 1:00 PM)

### Discovery Calls
- [ ] Review `templates/discovery_call_script.md` before each call
- [ ] Prepare custom notes for each prospect
- [ ] Conduct scheduled calls
- [ ] Take detailed notes during call
- [ ] Send follow-up proposal within 2 hours

### Follow-ups
- [ ] Reply to all email replies within 4 hours
- [ ] Follow up with proposals sent 48+ hours ago
- [ ] Check in with active clients if needed

---

## 🔧 Delivery Block (1:00-4:00 PM)

### Client Work
- [ ] Run `python scripts/research_automation.py` for active clients
- [ ] Process and clean data: `python scripts/data_processor.py`
- [ ] Create/update research reports
- [ ] Review quality before sending
- [ ] Deliver completed work to clients

### Automation Maintenance
- [ ] Check automation scripts are running correctly
- [ ] Fix any errors in logs
- [ ] Update lead lists if needed

---

## 📊 Evening Review (4:00-5:00 PM)

### Metrics Update (20 min)
- [ ] Update `tracking/metrics_tracker.csv`:
  - Emails sent
  - Replies received
  - Calls booked
  - Deals closed
- [ ] Update `tracking/revenue_tracker.csv` with any new payments
- [ ] Calculate today's conversion rates

### Planning (20 min)
- [ ] Identify what worked today
- [ ] Identify what to improve tomorrow
- [ ] Schedule any follow-up tasks
- [ ] Prepare tomorrow's lead list

### Learning (20 min)
- [ ] Read one article about agency marketing
- [ ] Test one new outreach variation
- [ ] Document learnings in notes

---

## 📅 Weekly Tasks (Every Monday)

### Review
- [ ] Calculate last week's MRR
- [ ] Review client retention (any cancellations?)
- [ ] Analyze best-performing email subjects
- [ ] Identify top lead sources

### Plan
- [ ] Set weekly targets (leads, emails, calls, revenue)
- [ ] Adjust email templates if reply rate < 8%
- [ ] Plan content for the week
- [ ] Review `business_model.md` growth milestones

### Client Management
- [ ] Schedule monthly check-ins with all active clients
- [ ] Request testimonials from satisfied clients (Month 1+ clients)
- [ ] Upsell opportunities review

---

## 📅 Monthly Tasks (1st of each month)

### Business Review
- [ ] Calculate total MRR vs target
- [ ] Review client churn rate
- [ ] Analyze CAC (Customer Acquisition Cost)
- [ ] Update `tracking/revenue_tracker.csv`

### Strategy
- [ ] Assess current month's performance vs `business_model.md` targets
- [ ] Decide on hiring if at capacity
- [ ] Review and update pricing
- [ ] Plan next month's growth initiatives

### Operations
- [ ] Update Python scripts if needed
- [ ] Audit automation workflows
- [ ] Backup all tracking data

---

## 🚨 Red Flags (Take Action Immediately)

- Email reply rate drops below 5% → Rewrite templates
- No calls booked in 3 days → Increase volume or change approach
- Client asks to cancel → Schedule retention call within 24h
- Revenue flat for 1 week → Double outreach volume
- Scripts producing errors → Fix before next run

---

## 💡 Quick Wins (Do These When Stuck)

1. Send a follow-up email to everyone you emailed 3-7 days ago
2. Post on LinkedIn asking "What's your biggest research challenge?"
3. Reach out to a past client for referrals
4. Create one new sample research report to share as free value
5. Run `python scripts/lead_generation.py` and add 25 new leads
