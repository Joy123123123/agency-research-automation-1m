# ✅ Daily Tasks Checklist

**Creator:** Md Jamil Islam  
**Purpose:** Keep you on track every single day

---

## 🌅 Morning Routine (30 min)

- [ ] Check emails & respond to leads (10 min)
- [ ] Review `tracking/client_tracker.csv` for follow-ups
- [ ] Set 3 main goals for the day
- [ ] Update revenue tracker

---

## 💼 Core Work Tasks

### Lead Generation (1 hour/day)
- [ ] Find 10 new agency leads
- [ ] Add to `tracking/client_tracker.csv`
- [ ] Enrich lead data (website, email, LinkedIn)
- [ ] Run `scripts/lead_generation.py` for bulk leads

### Outreach (1 hour/day)
- [ ] Send 10 cold emails using `templates/email_templates.md`
- [ ] Follow up on Day 2, Day 5, Day 10 emails
- [ ] Connect with 5 agencies on LinkedIn
- [ ] Track all outreach in `tracking/client_tracker.csv`

### Research & Delivery (2 hours/day)
- [ ] Complete any pending client research reports
- [ ] Use `scripts/research_automation.py` for efficiency
- [ ] Quality check all deliverables
- [ ] Send completed reports to clients

### Discovery Calls (as scheduled)
- [ ] Prepare with `templates/discovery_call_script.md`
- [ ] Take detailed notes
- [ ] Send follow-up proposal within 24 hours
- [ ] Log outcome in tracker

---

## 📊 Weekly Review (Every Friday)

- [ ] Count total emails sent this week
- [ ] Count discovery calls completed
- [ ] Count new clients closed
- [ ] Update `tracking/revenue_tracker.csv`
- [ ] Calculate week-over-week growth
- [ ] Plan next week's targets
