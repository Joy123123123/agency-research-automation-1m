# ✅ Daily Tasks Checklist

**Author:** Md Jamil Islam
**Purpose:** Daily execution checklist to hit $1M in 4 months

---

## 🌅 Daily Morning Routine (30 min)

- [ ] Check `tracking/metrics_tracker.csv` – review yesterday's numbers
- [ ] Check email for client replies
- [ ] Review today's task list
- [ ] Set 3 top priorities for today

---

## 📧 Daily Outreach Tasks (1–2 hrs)

- [ ] Send 5–10 personalized cold emails (use `templates/email_templates.md`)
- [ ] Send 5–10 LinkedIn connection requests to agency owners
- [ ] Follow up with leads from 2–3 days ago
- [ ] Respond to all inquiries within 4 hours
- [ ] Log all outreach in `tracking/client_tracker.csv`

---

## 🔬 Daily Research & Delivery (2–3 hrs)

- [ ] Run `scripts/research_automation.py` for active clients
- [ ] Review and quality-check automated reports
- [ ] Customize reports for client niches
- [ ] Send deliverables to clients on schedule
- [ ] Update `tracking/metrics_tracker.csv`

---

## 📞 Sales Activities (1 hr)

- [ ] Conduct scheduled discovery calls
- [ ] Send proposals to qualified leads
- [ ] Follow up on pending proposals
- [ ] Ask satisfied clients for referrals

---

## 🌆 Daily Evening Review (15 min)

- [ ] Update client tracker with today's activity
- [ ] Log revenue in `tracking/revenue_tracker.csv`
- [ ] Note what worked and what didn't
- [ ] Plan tomorrow's top 3 tasks

---

## 📊 Weekly Metrics to Track

| Metric | Weekly Goal |
|--------|-------------|
| Cold emails sent | 50–70 |
| LinkedIn messages | 30–50 |
| Discovery calls | 3–5 |
| Proposals sent | 2–4 |
| New clients closed | 1–3 |
| Revenue collected | $1K–$5K |

---

## 🗓️ Weekly Milestone Check

### Every Monday:
- [ ] Review last week's metrics
- [ ] Adjust outreach strategy if needed
- [ ] Set revenue goal for the week
- [ ] Check client satisfaction

### Every Friday:
- [ ] Send weekly reports to all active clients
- [ ] Update revenue tracker
- [ ] Identify top 3 learnings from the week
- [ ] Plan next week

---

## 🚨 Non-Negotiable Daily Habits

1. **Send at least 5 outreach messages** (email or LinkedIn)
2. **Deliver to all active clients on time**
3. **Follow up with every lead**
4. **Track all numbers** – what gets measured, gets managed
