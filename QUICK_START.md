**Time to first dollar:** 3–7 days

## 🗓️ Week 1 Action Plan

### Day 1 — Setup (2 hours)

- [ ] Read `README.md` top to bottom
- [ ] Install Python 3.9+ on your computer
- [ ] Run `pip install -r scripts/requirements.txt`
- [ ] Set up accounts: Apollo.io (free), Hunter.io (free tier), LinkedIn
- [ ] Read `resources/tools_setup.md`
- [ ] Set up a professional email (Gmail with custom domain recommended)

### Day 2 — Create Sample Work (3 hours)

- [ ] Run `python scripts/research_automation.py` with a sample company
- [ ] Create 2–3 sample research reports using `templates/research_report_template.md`
- [ ] Customize your email templates in `templates/email_templates.md`
- [ ] Create your agency name and simple logo (Canva free)

### Day 3 — Build Your Lead List (2 hours)

- [ ] Run `python scripts/lead_generation.py` to generate leads
- [ ] Target 50–100 businesses in your niche (e-commerce, SaaS, agencies)
- [ ] Verify emails using Hunter.io
- [ ] Fill out `tracking/client_tracker.csv` with your prospects

### Day 4 — Start Outreach (2 hours)

- [ ] Personalize the cold email template from `templates/email_templates.md`
- [ ] Send 20–30 emails per day (manually or via automation)
- [ ] Run `python scripts/email_outreach.py` for bulk campaigns
- [ ] Track opens/replies in `tracking/metrics_tracker.csv`

### Day 5 — Follow Up & Close (2 hours)

- [ ] Follow up with Day 3 contacts who opened but didn't reply
- [ ] Book discovery calls using `templates/discovery_call_script.md`
- [ ] Send proposals to interested leads
- [ ] **Goal: 1–2 paying clients by end of Day 7**

### Day 6–7 — Deliver & Invoice

- [ ] Deliver your first research report
- [ ] Invoice your first client ($500–$1,000)
- [ ] Request a testimonial/case study
- [ ] Start planning Month 1 scaling (see `business_model.md`)
